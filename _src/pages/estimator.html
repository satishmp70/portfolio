How the estimate is calculated

Each product type starts from the timeline we typically plan for a focused first version — for example, 4–6 weeks for a SaaS MVP or 3–5 weeks for a headless CMS website. The estimator then adjusts that range for:

  • Scale: a growth-scale platform adds about 2–3 weeks; enterprise scale adds about 4–6 weeks for high availability, observability and load testing.
  • Features: selecting more than three major features adds 1–2 weeks.
  • Security level: advanced security or compliance adds up to 2 weeks for threat modelling, audit logging and reviews.
  • Delivery speed: a fast-track plan shortens the timeline by running more work in parallel.
